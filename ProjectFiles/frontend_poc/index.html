Oven Demo · Supervisor PoCs
FactoryTalk Optix · Server-side UI proposal
Concept

Il server è un supervisory backend per una flotta di forni collegati via MQTT/OPC-UA, con recipe schema centralizzato, loggers, alarms e users. La UI server è quindi diversa dal client di macchina: densità informativa alta, layout desktop, navigazione per ruolo (Operations · Recipes · Alarms · Connectivity · Admin).

Design rationale

  • Layout desktop FHD: il server gira su iPC/PC, non su panel HMI.
  • Navigazione per ruolo, non per macchina: l’operatore di flotta cerca “quale forno è in allarme?”, non “che temperatura ha questo forno?”.
  • Drill-down esplicito: lista flotta → singolo forno, niente tutto-in-uno.
  • Densità tabellare per liste lunghe (ovens, recipes, alarms, sessions), card solo per i KPI di sintesi.
  • Same brand del client (#235d9f, Apple-minimal, light/dark) ma gerarchia diversa: qui contano griglie e tabelle, non simboli HMI.
